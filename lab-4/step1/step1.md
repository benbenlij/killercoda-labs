# Objective 1

As usual, make sure to read the README.

One of the first things you might've read was that unauthorized media is not allowed! This means no images, videos, audios, etc. However, the system will usually already have many media files, which you shouldn't delete! This policy typically means no media files in the home directory or `/home`.

This search can be done easily with the `find` command. Search for all media files (.jpg .png .mp3 .mp4 .wav) using `find`. Then, remove them using `rm`.
