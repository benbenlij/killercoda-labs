# Objective 2

The README also states that all "hacking tools" are strictly prohibited. While it may seem obvious that you aren't allowed to have tools that assist in hacking, many real cybersecurity jobs allow you to use these tools! They help companies strengthen their security before a real attacker gets to the vulnerability.

However, in this system, they are not allowed, so you must remove them. Search for how to find hacking tools by name. You will likely use a command called `dpkg`.


Find the hacking tool in the system and remove it using `apt`, a package manager for Linux (the hacking tool is a common one).
