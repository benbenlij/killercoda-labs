# Welcome to your first lab!

In this lesson, you will practice basic commands that help you to navigate around the large filesystem in the terminal!

The main commands you will practice in this lesson are `sudo`, `ls`, `cd`, and `man`.

Your objectives are to answer the forensics questions below:
-
1. An attacker created a hidden file in your directory. What is its name?

2. The attacker has a secret folder in `/opt` and using `ls` seems to not work on it. This is because the directory starts with a dash: `-`. Using `cd` instead, what is the name of the file in this directory?

3. There is another user in your system with a home directory. From previous users, he is known to be quite suspicious. What is the name of the secret diary in his home directory?

4. In the man page for `ls`, what does the option `-C` do? (You may copy its description)

Note your answers on a piece of paper or on a document. When you're done, check with the answer key!
