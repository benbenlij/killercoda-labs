# Linux Interactive Labs for Cyberpatriots
A light-weight learning tool for students to learn Linux cybersecurity skills in the terminal

# What are the Labs for?
Distributing virtual machines to completely new members of the cybersecurity club at my high school takes a lot of storage and hard to work with. My light-weight solution to provide hands-on Linux practice to students in preparation for CyberPatriots is to create Killercoda labs.
