# Objective 1

In your home directory, there is a file `hacker_info.txt`. 
You can find it by running `ls`.

To read the file's contents, run `cat hacker_info.txt`.
In the file, you will find the hacker's name.

Now, look into the Desktop directory (using ls).
You will see a few forensics questions. 

Enter the hacker's name into the first forensic question using `nano`.
Press Ctrl + S to save and Ctrl + X to exit.
